## 4. 숫자·날짜 표기
- 날짜: 본문 `2026. 11. 9.`(공문) 또는 `2026-11-09`(표·데이터), 파일명 `YYYYMMDD`·`YYMM`.
- 금액: `3,520만 원`, `0.12억 원`, 표에서는 단위를 머리글에 둔다(`금액(만 원)`).
- 비율: `30%`, 범위: `30~50%`. 기준일·출처를 같이 쓴다(`2025년 기준, 고용노동부`).
- 차량 대수: 대외 문서·SNS에는 쓰지 않는다. 꼭 필요하면 `1,000대 이상`만.

## 5. 금지·주의 표현
| 쓰지 않음 | 대신 |
|---|---|
| ~하느냐에 따라 (반복) | ~에 좌우된다 / 적용 기준에 따라 상이하다 / ~별로 다르다 |
| 제때 | 정시에, 약속한 시각에, 예정대로 |
| 최고의, 완벽한, 업계 1위(근거 없는 최상급) | 구체 수치·인증·연혁 |
| 수익 보장, 월 ○○○만 원 보장(지입) | 쓰지 않는다 |
| 지입 계약 전 비용 확인·금전 요구 관련 문구 | 쓰지 않는다 |
| 겨울철(11월 7일~11월 말) | 추위, 기온이 내려가는 시기 (12월부터 '겨울') |
| AI가 작성한 티가 나는 말: "~에 대해 알아보겠습니다", "결론적으로", "다양한", "혁신적인" | 바로 요지, 구체 동사 |
